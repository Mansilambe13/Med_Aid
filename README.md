# MediVision AI — Multimodal Medical Diagnostic Assistant

An end-to-end AI-powered medical assistant that combines chest X-ray disease detection, handwritten prescription digitization, and LLM-driven clinical analysis in a single Streamlit web application.

---

## Features

- **Chest X-ray Classification** — DenseNet-121 detecting 14 thoracic conditions with per-class AUROC evaluation
- **Prescription OCR** — Microsoft TrOCR (`trocr-small-handwritten`) for handwritten prescriptions; Tesseract for printed PDFs
- **Clinical Analysis** — Gemini 2.0 Flash Lite for drug interaction analysis, differential diagnosis, and treatment plan generation
- **Medical Q&A Chat** — Real-time conversational medical assistant

## Dataset

- **Source**: NIH ChestX-ray14 (small subset via deeplearning.ai AI for Medicine curriculum)
- **Train**: 1,000 images (`train-small.csv`)
- **Validation**: `valid-small.csv`
- **Test**: 420 images (`test.csv`)
- **Patient-level leakage prevention**: verified via `PatientId` disjoint splits — no patient appears across multiple splits

## Architecture

```
MediVision AI
├── X-ray Module       DenseNet-121 (ImageNet pretrained) + GAP + Sigmoid(14)
├── OCR Module         Microsoft TrOCR (handwritten) + Tesseract (printed PDF fallback)
├── LLM Module         Gemini 2.0 Flash Lite (Google Generative AI)
└── Frontend           Streamlit multi-tab web app
```

## Setup

```bash
git clone <repo-url>
cd medaidmodel

# Create and activate virtual environment
python -m venv medenv
medenv\Scripts\activate       # Windows
source medenv/bin/activate    # Mac/Linux

pip install -r requirements.txt
pip install scikit-learn      # for evaluation script
```

Set up your `.env` file:
```
GEMINI_API_KEY=your_key_here
```

Run the app:
```bash
streamlit run ocr.py
```

---

## Reproducing Metrics

```bash
python evaluate_metrics.py
```

Update the paths in the CONFIG section of `evaluate_metrics.py` to point to your local NIH dataset and model weights. Results are saved to `metrics_output.csv`.
